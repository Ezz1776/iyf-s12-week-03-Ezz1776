Exercise 2: Create Project Structure



Commands used:



1\. cd \~

&#x20;  Navigate to the home directory.



2\. mkdir -p my-project/src/{css,js,images} my-project/docs my-project/tests

&#x20;  Create the project folders.



3\. touch my-project/README.md

&#x20;  Create the README file.



4\. ls my-project

&#x20;  List the project contents.



5\. ls my-project/src

&#x20;  List the src folders.



6\. touch terminal-log.md

&#x20;  Create the terminal log file.
